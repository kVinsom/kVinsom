## Featured Projects

### [IATROS DevOps](https://github.com/kVinsom/Iatros)

An early-stage, provider-neutral DevOps automation platform written in Go. Its current local-first CLI workflows analyze repositories and model project topology without modifying user files.

- Bounded, ignore-aware repository discovery.
- Technology detection and conservative production-readiness checks.
- Project, workspace, component, manifest, and dependency topology analysis.
- Deterministic text and JSON reports with explicit safety limits.
- Architecture, security, testing, and product documentation.

**Stack:** Go, CLI tooling, architecture decision records, automated tests

### [Contact Manager](https://github.com/kVinsom/Technical-Task)

A full-stack application for importing, browsing, editing, and deleting contacts.

- ASP.NET Core REST API built with Clean Architecture and DDD-oriented boundaries.
- React and TypeScript client with a responsive, accessible interface.
- Server-side pagination, sorting, search, and validated CSV import.
- Microsoft SQL Server persistence with Dapper and `SqlBulkCopy`.
- Backend unit and integration tests plus frontend component tests.

**Stack:** .NET 10, ASP.NET Core, React 19, TypeScript, SQL Server, Docker, xUnit, Vitest

### [Banking Platform](https://github.com/kVinsom/Bank-monorepo)

A service-oriented banking platform composed of an HTTP API, two gRPC services, and shared Protocol Buffers contracts.

- REST gateway for public banking operations.
- Separate persistence and exchange-rate services communicating through gRPC.
- PostgreSQL and Redis for durable storage and caching.
- Kafka-based audit and domain-event flows.
- Docker Compose and Kubernetes deployment configurations.
- Unit, integration, race, and API-level test workflows.

**Stack:** Go, Gin, gRPC, Protocol Buffers, PostgreSQL, Redis, Kafka, Docker, Kubernetes

Core repositories:

- [Bank Backend](https://github.com/kVinsom/Bank-backend)
- [Bank Repository Service](https://github.com/kVinsom/Bank-repository-service)
- [Bank Exchange Rate Service](https://github.com/kVinsom/Bank-exchange-rate-service)
- [Bank Protocol Contracts](https://github.com/kVinsom/Bank-proto)
